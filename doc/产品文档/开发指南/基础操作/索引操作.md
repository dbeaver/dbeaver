本文档介绍如何在DBeaver中创建，查看，编辑，删除YashanDB的索引。
## 权限需求
使用DBeaver For YashanDB管理索引，请确保当前用户具有以下权限。


| 权限               | 说明                          |
|------------------|-----------------------------|
| CREATE ANY INDEX | 对数据库中任意表创建索引（sys schema除外）  |
| ALTER ANY INDEX  | 对数据库中任意索引修改属性（sys schema除外） |
| DROP ANY INDEX   | 删除数据库中任意索引（sys schema除外）    |

## 创建索引
创建示例SQL语句
```sql
CREATE TABLE TEST01.area
(area_no CHAR(2) NOT NULL PRIMARY KEY,
 area_name VARCHAR2(60),
 DHQ VARCHAR2(20) DEFAULT 'ShenZhen' NOT NULL);
```

在左侧点击**模式**，点击**schema**，点击**索引**，将展示创建的索引。

![查看索引](./image/查看索引.png)

**双击**索引，查看**索引详情**。

![查看索引详情](./image/查看索引详情.png)

## 编辑索引

在左侧点击**模式**，点击**schema**，点击**索引**，点击**工具**，点击**rebuild index**。

![编辑索引](./image/编辑索引.png)

在上方**修改**内容，点击**process**进行保存。

![编辑索引弹框](./image/编辑索引弹框.png)


## 删除索引

在左侧点击**模式**，点击**schema**，点击**索引**，点击**delete**。

![删除索引](./image/删除索引.png)
