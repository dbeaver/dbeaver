本文档介绍如何在DBeaver中管理物化视图。

## 权限需求
使用DBeaver For YashanDB管理物化视图，请确保当前用户具有以下权限。


| 权限                           | 说明                                 |
|------------------------------|------------------------------------|
| CREATE MATERIALIZED VIEW     | 在用户自己的schema下创建sequence            |
| CREATE ANY MATERIALIZED VIEW | 在任意schema下创建sequence（sys schema除外） |
| ALTER ANY MATERIALIZED VIEW  | 对数据库中任意sequence修改属性（sys schema除外）  |
| DROP ANY MATERIALIZED VIEW   | 删除数据库中任意sequence（sys schema除外）     |

## 创建物化视图
创建示例SQL语句
```sql
CREATE MATERIALIZED VIEW TEST01.MATERIALIZED_VIEW BUILD IMMEDIATE AS SELECT * FROM TEST01.AREA;
```


1.在左侧点击**模式**，点击**schema**，右键点击**物化视图**，点击**新建物化视图**。

![创建物化视图](./image/创建物化视图.png)

2.输入名称，创建列，点击**Save**，再点击**Persist**，创建成功。

![保存物化视图](./image/保存物化视图.png)

## 查看及修改物化视图

1.双击对应物化视图名称查看名称、注释、相关属性及字段信息。

![查看物化视图](./image/查看物化视图.png)

2.双击列后的**Comment**，修改物化视图注释。

![修改物化视图注释](./image/修改物化视图注释.png)

3.点击**Constraints**，查看物化视图相关的约束。

![查看物化视图约束](./image/查看物化视图约束.png)

4.点击**Declaration**，查看物化视图DDL。

![查看物化视图DDL](./image/查看物化视图DDL.png)

5.修改DDL后点击**Save**，再点击**Persist**，修改成功。

![修改物化视图DDL](./image/修改物化视图DDL.png)

6.点击**Data**，查看物化视图的数据。

![查看物化视图数据](./image/查看物化视图数据.png)

7.双击对应数据，修改数据后点击**Save**，再点击**Persist**，修改成功。

![修改物化视图数据](./image/修改物化视图数据.png)
