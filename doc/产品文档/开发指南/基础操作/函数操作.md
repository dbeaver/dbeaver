## CREATE FUNCTION
创建示例SQL语句
```sql
CREATE OR REPLACE FUNCTION ya_proc(i INT) RETURN VARCHAR
IS
BEGIN
CASE i
WHEN 1 THEN
RETURN 'hello';
WHEN 2 THEN
RETURN 'world';
END CASE;
END ya_proc;
```

在左侧点击模式，点击schema，点击函数，点击新建函数,输入名称。
