## 概述

DBeaver For YashanDB基于流行的开源图形化工具DBeaver，在严格遵循DBeaver Community Edition 的ASL开源协议基础上，进行了二次开发和封装，支持管理单机、集群和分布式三种形态的YashanDB数据库图形化开发及管理。

## 产品功能

- 数据库对象管理
  - 支持管理多形态表（HEAP，LSC）
  - 支持管理物化视图
  - 支持管理自定义类型
  - 支持管理存储过程
  - 支持管理函数
  - 支持管理同义词
  - 支持管理调度器和Jobs
  - 支持管理回收站
  - 支持管理DBLink
- SQL语句开发
  - 支持SQL智能补全
  - 支持SQL格式化
  - 支持运行SQL文件
- PL/SQL调试
  - 支持断点调试和单步调试
  - 支持查看调试中变量值实时变化

## 限制说明

| 限制项           | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| 版本兼容         | 目前只兼容23.1.x版本的YashanDB，其他版本YashanDB可以进行试用。 |
| 环境要求         | DBeaver For YashanDB需要在JDK17环境进行使用。                |
| YashanDB形态适配 | YashanDB不同部署形态特性具有差异，遇到某个形态不支持的功能，DBeaver For YashanDB会提示功能暂未实现或报错。例如，23.1版本分布式不支持DBLink。 |
| 表管理           | 暂不支持通过图形化界面创建二级分区，建议此类复杂语法使用编辑器执行。 |
| PLSQL调试        | 不支持console输出调试过程中的打印信息； 不支持变量的动态设置；不支持变量表达式的计算；函数或存储过程的参数现在只支持整数， 浮点，字符串类型；不支持suspend，disconnect功能；不支持条件断点；不支持表达式计算；不支持运行到下一个异常处；不支持在debug configuration页面修改debug对象。 |
| 数据查看和编辑   | 不完全支持通过图形化界面直接修改表数据，此功能可以试用。ST_GEOMETRY数据不支持编辑，查看默认使用ST_AsText函数进行展示。 |
| 导入导出         | 暂不支持YashanDB连接源的数据导入导出功能。                   |

如需了解更多使用功能，请点击以下链接浏览官方文档：[https://dbeaver.com/docs/wiki/](https://dbeaver.com/docs/wiki/)。
