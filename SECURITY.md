# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to [security@dbeaver.com](mailto:security@dbeaver.com). Please include the affected version, a description of the issue, steps to reproduce it, and its potential impact.

Confirmed vulnerabilities are prioritized based on severity, exploitability, and user impact, with target remediation timelines defined in the full security policy.

## Full Security Policy

For more information, see the [DBeaver Security Policy](https://dbeaver.com/dbeaver-security-policy/), which covers vulnerability reporting, severity assessment, target remediation timelines, coordinated disclosure, supported versions, and guidelines for security researchers.
